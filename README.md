# CAN 问题与建议

这里用于收集 **Cerulean Aviation Network** 的 Bug、数据错误、文档问题和功能建议。
每个被确认有效的 issue，均可获得 **1–5 个 CAN 平台积分**。

## 可以提交什么

- **Bug**：功能报错、页面无法使用、数据展示错误、客户端异常等。
- **数据问题**：机场、航路、程序、频率、地面图或其他网络数据错误。
- **文档问题**：说明不准确、链接失效、步骤缺失或中英文内容不一致。
- **功能建议**：具体、可执行，并能改善飞行、管制或平台使用体验的建议。

账号、积分余额、兑换、个人投诉等需要查询个人信息的事项，请通过平台反馈渠道提交，不要在这里公开个人资料。

安全漏洞、密钥泄露和可能造成数据损失的问题不要公开创建 issue，请使用注册邮箱发送至 [feedback@ceruleanavi.net](mailto:feedback@ceruleanavi.net)。

## 提交要求

标题请直接说明问题，并尽量使用以下前缀：`[Bug]`、`[数据]`、`[文档]` 或 `[建议]`。

正文至少应包含：

1. **问题描述**：实际发生了什么，影响了什么功能。
2. **复现步骤**：按顺序写出进入页面、使用功能或执行操作的步骤。
3. **预期结果与实际结果**：说明本来应该怎样，以及现在看到了什么。
4. **环境信息**：网址或客户端、操作系统、浏览器、版本、时间和相关航班/机场；适用时附截图、日志或最小复现数据。

功能建议还应说明使用场景、希望解决的问题和可接受的结果。提交前请先搜索已有 issue，避免重复报告。

## 积分规则

积分按下列方式计算，单个 issue 最多 5 分：

| 项目 | 分值 | 判定标准 |
| --- | ---: | --- |
| 有效受理 | +1 | 问题属于本仓库范围，内容真实、可理解，且不是重复报告。 |
| 信息完整 | +1 | 提供清晰的复现步骤、环境和证据；功能建议有明确场景和验收标准。 |
| 技术贡献 | +1 | 提供根因分析、数据修正方案、补丁或可直接使用的 Pull Request。 |
| 影响范围 | +0 | 仅影响个人、低频场景或文字细节。 |
| 影响范围 | +1 | 影响一个功能模块、较多成员或常见使用场景。 |
| 影响范围 | +2 | 影响大范围成员、核心功能不可用、数据错误扩散，或经确认的严重安全问题。 |

例如：一个可稳定复现、只影响少量用户的 Bug，通常为 2 分；附带完整复现信息和修复补丁的同类问题，通常为 4 分；影响全体成员的核心服务故障，最高可得 5 分。

以下情况不发放积分：重复 issue（积分归最早的有效报告）、无法验证或信息不足且未补充、超出本仓库范围、恶意或滥用提交，以及仅重复已有讨论而没有新增信息的评论。

## 发放方式

1. 维护者先确认 issue 是否有效，并在需要时要求补充信息。
2. 问题完成修复、建议作出采纳或不采纳决定后，维护者确定最终分值并关闭 issue。
3. 积分由管理组发放到提交者的 CAN 账号。请在 issue 中提供可关联的 CAN ID；不要公开密码、令牌或其他敏感信息。
4. 一个 issue 只发放一次积分；后续评论、重复修复或同一问题的再次提交不重复计分。
5. 如 issue 关闭后确认是回归问题或影响范围明显扩大，管理组可以重新评估分值。

积分最终以维护者核实结果为准。对分值有异议时，请在原 issue 中说明依据，管理组会复核一次。
